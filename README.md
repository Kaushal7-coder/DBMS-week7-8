The assignment is based on a Supplier Database that maintains information about suppliers, parts, and the costs at which suppliers provide different parts.

## Database Schema

The database consists of three tables:

1. **Supplier** - Stores supplier ID, supplier name, and city.
2. **Part** - Stores part ID, part name, and color.
3. **Catalog** - Stores supplier ID, part ID, and cost.
